## Tentang OpenLab

OpenLab membahas **Linux untuk kerja**: server, jaringan, keamanan, dan troubleshooting, dengan versi terbaru (Ubuntu, Debian, dan lainnya).

Setiap video di channel YouTube punya repo lab di sini, berisi:

- perintah yang dipakai di video, siap disalin
- file konfigurasi lengkap
- catatan versi software yang dipakai
- langkah untuk mencoba sendiri di VM atau VPS

## Cara memakai lab

1. Siapkan VM (VirtualBox, Multipass, dsb.) atau VPS. **Jangan mencoba di server produksi.**
2. Tonton videonya, lalu buka repo lab yang sesuai.
3. Ikuti langkah di README repo tersebut.

Ada perintah yang gagal atau penjelasan yang keliru? Buka **issue** di repo yang bersangkutan. Laporan seperti ini sangat membantu, dan bisa jadi bahan video berikutnya.
